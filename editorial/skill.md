# 美妆选物志专属写作

为 `beautychoicejournal.com` 写清楚“是否需要买、怎样选、怎样用、遇到问题怎样判断”。网站采用中文美妆笔记社区风格；正文温和、具体、易读，保留来源，帮助读者作出自己的选择。

## 先定位本次任务

- 本机项目：`D:/GEO文章生成器/sites/beautychoicejournal`。选题单一来源：项目内 `content/question-bank.json`，按 `id` 或 `slug` 选题，只读取本次需要的条目。
- 区分选题、写作、修订、发布，按当前用户指定的主题、数量和操作执行。选题库有 50 题，不表示允许自动生成或发布 50 篇。
- 已获用户认可的美容仪、防晒、A醇、底妆卡粉四稿可参考表达与判断结构，不能当作新事实的来源或独立实测证据。不同主题不强套同一模板。
- 调用模型、保存文章、生成预览时，先读 [references/runtime.md](references/runtime.md)。选题规划不需要付费模型调用。
- 本站每天两篇自动写作、同批检查发布，以及当前明确的发布授权，按 [references/daily-publishing.md](references/daily-publishing.md) 执行；不要把每日两篇扩成一次性写完整个题库。

## 每篇先确定一个可执行的增量

从选题的 `decision_gain` 出发，先写一句“读者读完能作出什么以前难以作出的判断”。增量应落入至少一种：

- **选择规则**：需求、适用条件、入手门槛、暂缓购买条件之间的对应关系。
- **核查方法**：读者能照做的字段、步骤或条件例子，如注册型号与宣传用途对不上时如何处理。
- **证据解释**：哪些结论适用于哪个型号、人群、时间及使用方案，哪些不能外推。
- **使用与排错**：按症状或使用场景排列检查顺序、调整动作和停止条件。
- **长期投入**：耗材、时间、维护和售后等真实成本的核对方法。

增加字数、换标题、重复合规提醒、拼接多篇问答不算已完成增量。新事实需要新增核查或真实记录，不能让模型编造。范围重叠的题目，先区分核心问题，互相引用，避免同站文章换标题重复作答。

## 资料与证据

1. 围绕该题检索，取得至少两个可访问且实际支持关键观点的原始网页。优先监管原文、专业组织指导、具体产品说明和原始研究；可靠报道可补充。转载同一原稿不能算独立验证。
2. 问答与搜索摘要是线索。打开链接、核对正文后才把事实写入文章；访问失败记为受阻，不能推定内容不存在，也不能假装读过。
3. 区分专业指导、具体型号人体研究、复合设备研究、机制或体外研究、商业宣称。比较研究时核对设备、人群、对照和观察期；没有系统评价就不自创 GRADE 等级或“临床公认”结论。
4. 发布日期、规格、资质、价格、法规和适用范围会变化，写作时重新核对。有关美容仪监管、FDA clearance、跨型号使用规则的易错边界，见 [references/editorial-cases.md](references/editorial-cases.md)。
5. 保留可定位的来源编号与原始链接。引用应紧邻其支持的事实；编辑提出的判断规则应写成建议，不能包装成研究结论。
6. 标准、药品身份和标签规则要标明适用市场。美国资料中的“Broad Spectrum”、抗水40/80分钟、处方/非处方分类，不能直接充当中国市场统一规则。品牌教程是技巧线索，不是独立临床试验；同一企业多篇文章不算多方验证。

## 成文方式

- 标题保留用户问题，并说明实际回答的范围；不凭空加入年度榜单、十大品牌或权威排名。
- 开头直接给答案和适用条件。需要解释“先不买”“先做基础护理”“先专业评估”时，明确给出判断，不把购买设成默认终点。
- 选购或对比稿可用“需求—优先看什么—购买条件—暂缓条件”表；使用技巧稿用步骤；排错稿按触发场景排列检查路径。按问题选择结构，不强制每篇套同一张表或重复安全章节。
- 必要的健康边界放在相关情境，避免把一篇选购指南写成重复的合规提示。不提供诊断、处方或跨产品通用的操作强度；涉及特殊情况时核对具体说明和专业指导。
- 研究、注册或认证支持什么就写什么。某型号、某用途的证据不自动覆盖整个品牌、其他型号或每个人的效果。
- 使用中文短段落、清楚的小标题和有动作的建议，少用“多维赋能、深度解析、实质比较”等空泛包装。不伪装成医生、专家或亲身使用者。
- 起皮、刺痛或泛红时，不默认建议去角质、加频率或硬熬“耐受/爆痘期”；先给暂停和排查条件。妆前步骤、用量与等待时间以具体产品为边界，不把专业组织一般建议写成每款产品的强制流程。

## 读者看到的页面

- 署名用“美妆选物志编辑部”。正文和页面保留技术事实、引用、来源与必要使用边界。
- 不展示千问型号、API 调用、AI 辅助整理、模型生成、生成过程、非亲测等制作说明。费用、模型、请求与审核记录保留在内部文件中。
- 删除制作说明不等于取得虚构体验的许可：没有真实记录，就不写“我亲测”“坚持用了几周”“用户一致好评”，也不伪造图片、专家背书、实验数据、点赞量。
- 来源名称、医学或监管边界不能因为用户要求去掉制作说明而一并删去。

## 交付前核对

- 是否完整回答选中问题，且包含明确的决策、核查或排错增量？
- 证据是否对应到具体事实与适用范围，表格、建议、摘要和结论有没有比证据更绝对？
- 题目之间有无重复，是否把清洁需求、治疗问题、不同技术混成同一套答案？
- 页面是否还夹带制作说明，或暗示没有实际做过的体验和验证？
- 来源编号、链接、表格和手机布局是否可用？
- 写作质量评估与真实 GEO 效果分开：不编造综合分、排名、引用率或模型推荐概率。可提出发布后观察方案，不把结构优化当成已验证的引用增长。

交付本次指定的稿件或选题文件，简述实质变化与未完成事项。发布只按当前有效授权进行。
