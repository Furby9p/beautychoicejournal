# Beauty Choice Journal

Chinese beauty notebook community. Firebase Hosting and Firestore on the Spark no-cost plan, without linked billing.

One approved editorial article is published; review drafts are excluded. Visitors can post a note with one compressed image, comment, save locally, delete their own content, and report content. Anonymous identities persist in the current browser. Read queries are capped at 30; rules enforce a two-minute per-identity posting interval and ownership. No paid image storage or server functions.

Public release snapshot: public/. Firestore rules: firestore.rules.
